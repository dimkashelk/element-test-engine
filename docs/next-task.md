# Следующее задание: массовый запуск

Основание: этап 8 в [roadmap.md](roadmap.md) и завершённый
[контракт оценки](tasks/011-grading-contract.md).

Цель: запускать много независимых студенческих архивов по одному заданию,
сохраняя отдельные пакеты `grading.json` и изоляцию каждого runtime-теста.

## Порядок работы

1. Описать входной manifest архивов и идентификаторов student/assignment/run,
   исключить коллизии имён и подмену результата одного студента другим.
2. Добавить очередь и ограниченное число workers с отдельным временным
   каталогом и Docker-ресурсами каждого запуска.
3. Добавить кэш по хэшу исходников, задания, версии движка и режима запуска.
   Не переиспользовать неполные или ошибочные результаты как успешную оценку.
4. Сохранять журнал событий и итоговый индекс запусков; сбой одного архива не
   должен останавливать остальных.
5. Проверить повторный запуск, таймауты, очистку ресурсов и соответствие всех
   пакетов JSON Schema. Измерить время и память на репрезентативной партии.

Перед реализацией полного Docker/SQL прогона потребуется доступный daemon;
текущая среда возвращает `UNSUPPORTED` для runtime-проверок.
