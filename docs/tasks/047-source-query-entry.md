# Задание №47: исходные query, срез без скобок и отдельный XBQL

Статус: **реализовано**, 11 октября 2026 года. Приоритет P0.
Основание: [план типов проверок](../test-type-development-plan.md),
[контракты №46](046-dump-test-type-contracts.md).

Добавлен общий `runtime.querySource`: исходный литерал или XBQL выбирается
по файлу, точному диапазону и проверяемым хэшам. Planner хранит owner,
исходный текст, AST и зависимости. Вход XBQL исполняется без искусственного
метода и без изменения исходника. Параметры типизированы; исполнение использует
существующие storage/query adapters, сравнение — SBSL.

Срезы без скобок поддержаны с сохранением исходных позиций. Повторное чтение
после типизированной записи использует свежий storage и ранее захваченную
границу. Неявная граница учитывает фиксированные часы. Смешанный CASE цены
и строки получает скалярный union; NULL и описания колонок сохраняются.
Добавлены наблюдения rows/cardinality/columns/resource, повторные execute/write,
изоляция и путь Memory/PostgreSQL с независимым SQL audit.

[Исполняемый контракт, примеры и точные ограничения](../source-query-execution.md).
[Измерения](../test-type-stage-047-measurements.json) отделяют приёмку общего
механизма от подготовки исходников. Пять из пяти query-форм финального дампа
валидируются, планируются и генерируются. Их adapter/technicalAcceptance
остаются not-checked; PASS по финальному приложению не объявляется.

Технические проверки охватывают селекторы/неоднозначность/устаревшие хэши,
типизированные скаляры и массивы, исходные диапазоны, отсутствие фиктивных
методов и expected в plan, срезы День/Секунда/Момент, пустое состояние,
повторную запись, изоляцию, LEFT JOIN/NULL/CASE, ресурсы, транзакцию,
PostgreSQL и public test/run/batch. Независимое неверное ожидание даёт SBSL FAIL;
UNSUPPORTED сохраняет unavailablePoints. Затронутые прежние контракты проверены
целенаправленно; полная регрессия остаётся nightly.

Результат: **16/16** целевых проверок успешны, включая Memory/PostgreSQL.
Среди затронутой регрессии — **43** успешные проверки; **63** opt-in сценария
не запускались. Public test/run: PASS/FAIL/UNSUPPORTED, score 2, maxScore 4,
unavailablePoints 3. Batch: два намеренных FAIL, без inputError/incomplete;
ожидания фиксированы независимо от результатов query.

Архивы, существующие assignments/expected, исторические свидетельства и
расписание CI не менялись. Бизнес-сценарии финального дампа не создавались.
