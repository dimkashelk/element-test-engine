# P0: составной xdump и служебные метаданные

## Контракт

- `Ресурсы.yaml` и варианты `ЛокализованныеСтроки.yaml` загружаются с теми же
  ограничениями YAML и сохраняются в `serviceFiles`. Основной объект
  `ЛокализованныеСтроки` остаётся также в `elements` для совместимости.
- В `ФрагментКомандногоИнтерфейса` группа `Элементы` содержит команды с `Тип`
  и ссылки вида `=...`; требование `Имя` к ним не применяется.
- Составной архив выбирает единственное приложение автоматически. Опция
  `--project-name` выбирает проект по имени или `Поставщик::Имя`; в manifest
  партии для этого служит необязательное `projectName`.
- Каждая объявленная библиотека должна находиться рядом с приложением и точно
  совпадать по поставщику, имени, версии и `ВидПроекта: Библиотека`. Отсутствие,
  несовпадение и неоднозначность дают ошибку входа.
- Модель хранит `projectIdentity` и отдельные модели `libraries`. Пакет оценки
  и HTML показывают идентичность библиотек. Общий `sourceHash` включает байты
  всех файлов приложения и подключённых библиотек, включая ресурсы; изменение
  одной библиотеки меняет ключ структурного кэша `batch`.

## Проверка на исходных дампах

- `ДемоСРМ`: `inspect` завершился с кодом 0: 74 объекта и 48 модулей.
- `БазаЗнаний` из `autocheck`: отдельный `inspect` с
  `--project-name e1c::БазаЗнаний` завершился с кодом 0: 129 объектов и 112
  модулей.
- Исходный `autocheck` при выборе `dimkashelk::check` выдаёт код 2 и точный
  путь `Проверка/ПакетПроверки/КритерийПроверкиФормаОбъекта.yaml`, строка 112.
  Содержимое исходного дампа не менялось. На временной копии с исправленным
  экранированием `inspect` загрузил приложение и библиотеку версии 1.1.1;
  структурный `test` записал библиотеку в `result.json`, `grading.json` и HTML.

Исправление многострочной сигнатуры `Пространства.xbsl:70` и задания по новым
проектам [подготовлены в P1](018-multiline-index-and-reference-assignments.md).
Модель хранит библиотечные объекты отдельно; критерии, которые обращаются к
ним, получили [отдельный контракт](019-library-checks-and-runtime-verification.md).
