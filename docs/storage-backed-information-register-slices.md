# Срез последних регистра сведений — контракт №33

`storage-slice-last-day-v1` расширяет общий query AST №31. Python разрешает
владельцев, типы и диапазоны и генерирует код; Script выбирает строки из текущего
staging наборов №32. SBSL сравнивает независимые ожидания и вычисляет баллы.
Один ExecutionPlan используется в `test`, `run`, `batch`, memory и PostgreSQL.

## Основания и граница подтверждения

2 октября 2026 года через браузер проверена официальная
[СрезПоследних Элемента 9.1](https://1cmycloud.com/console/help/element/9.1/docs/stdlib/element/xbql/Std/InformationRegisterName/InformationRegisterName.SliceLast_ru/).
Параметр — Дата?, верхняя граница включительна; выбирается максимальный период
для каждой комбинации всех измерений. Возвращаются сохранённые измерения,
ресурсы, реквизиты и Период. Дополнительные вычисляемые поля этой страницы
не входят в данный адаптер. Соответствующий URL 9.0 возвращает 404.

Native-пробы Script дистрибутива 10.0.2-1 с `-c 9.0` подтверждают сравнение
Дата, точность День, получение текущей даты UTC и структурное сравнение
nullable-ссылки с заполненной ссылкой. Native литерал Запрос отсутствует.
Это проверка операций executor, а не native исполнения XBQL или платформенной
базы. SQL NULL не превращается в обычное XBSL Неопределено: предикат nullable
ссылки требует заполненный параметр и явную проверку заполненности поля.
Nullable-параметры ГДЕ и остальные NULL-операции дают UNSUPPORTED.

Фраза документации об актуальности при Неопределено не позволяет доказать
поведение будущих записей в платформенной базе. Поэтому адаптер **явно**
фиксирует этот выбор: пустой аргумент и `%{Неопределено}` означают текущую дату
**UTC, полученную в Docker при создании запроса**. Будущие строки исключаются.
Это объявленный контракт адаптера; платформенное поведение будущих строк не
выдаётся за подтверждённое. `query:slice-boundary:YYYY-MM-DD` сохраняет captured
границу в storageTrace. Отдельные доверенные Docker `date -u` снимки окружают
проверку; дата Python не используется. Часовой пояс UTC постоянен и независим
от часового пояса host. Повтор Выполнить сохраняет границу, включая переход суток.

## Исполнение

1. Параметры даты и ГДЕ вычисляются слева направо при создании запроса.
   Повтор простой переменной использует один slot; отдельные выражения
   наследуют контракт №31. Ссылочные параметры копируются.
2. Каждое Выполнить заново читает все buckets разрешённого metadata-owner из
   текущей storage-сессии. Учитель задаёт историю через initialRegisters и
   общий API записи №32; он не задаёт ответы запроса.
3. Script исключает периоды после границы, группирует по всем типизированным
   измерениям и выбирает максимальный период. Ключ содержит имена и типы
   измерений; nullable-значение сохраняется явно. Owner отделяется таблицей
   сессии. Одинаковые UUID разных ссылочных типов не смешиваются.
4. ГДЕ применяется **после** среза: подходящая старая цена не заменяет
   последнюю неподходящую. Затем идут сортировка, ПЕРВЫЕ и проекция.
5. Результат — свежий detached-массив readonly-строк №31. Старый результат
   и вложенные ссылки независимы от нового чтения, записи и rollback.

Сортировать можно по нескольким не-nullable Число/Строка/Дата, включая Период,
не вошедший в проекцию. Без полного порядка сортировки выбор строки при равных
ключах не гарантируется. Точные ожидания должны устранять такие равенства.
Сохранение и уникальность измерения+период наследуются от №32.

Чтение видит собственные записи и исходные зависимости в транзакции;
само не вызывает commit или SQL-публикацию. SQL backend исполняет тот же
Script и независимо читает опубликованную исходную историю через SELECT.
Проверка с injected publication failure подтверждает отсутствие публикации
при read-only срезе. ERROR сохраняется после общего catch/rollback; отказы,
TIMEOUT, invalid_test, unavailablePoints и следующий успешный запуск сохраняют
прежние контракты. Credentials и ресурсы очищаются инфраструктурой №30–32.

## Формы и ограничения

Поддержан один `Owner.СрезПоследних()` или
`Owner.СрезПоследних(%Дата)` / `Owner.СрезПоследних(%{выражение})`,
периодичность День, namespace/import/alias, квалифицированные/краткие поля,
проекции сохранённых полей, равенство/И, сортировка и ПЕРВЫЕ. План хранит
source_kind, owner, periodicity, полный dimensions, period_slot, period_range,
source_range, source_name, boundary, типы и исходные диапазоны параметров.
Teacher expected и строки истории в IR не включаются.

СрезПервых, другие периодичности, аргументы кроме даты, обычная таблица
регистра как новый источник, JOIN, агрегаты, вычисляемые проекции,
СледующийПериод/КлючЗаписи, nullable-сортировка, union-измерения и общий
NULL/XBQL API остаются UNSUPPORTED. Также сохраняются ограничения №32:
полный фильтр записи, отсутствие обработчиков самого набора и конкурентных
сессий. Владелец среза требует явного storage.registers; затенённые и
неоднозначные источники отклоняются. Проектные методы с таким же именем
исполняют свой исходник.

Именованное ЗАПОЛНИТЬ существующую YAML-структуру расширяет этот IR
в [№39](storage-query-fill.md): constructor/defaults, единый номинальный тип
и независимые ссылки результатов. Прочие ограничения среза сохраняются.

## Воспроизведение

```bash
bin/element-test test --project tests/corpus/information-register-slices/prices \
  --assignment assignments/slices-prices --output result/slices-prices
bin/element-test run --project Prakticheskie-primery-2026-09-30-15-20.xdump \
  --assignment assignments/slices-real --output result/slices-real
ELEMENT_TEST_DOCKER_TESTS=1 ELEMENT_TEST_INTEGRATION_TESTS=1 \
  python3 -m unittest discover -s tests -p test_information_register_slices.py -v
```

SQL-задания имеют суффикс `-sql` и требуют `--integration` и временного
ELEMENT_TEST_INTEGRATION_PASSWORD. Контрольное задание slices-control содержит
независимые FAIL → UNSUPPORTED → PASS. Корпус и native-пробы находятся в
[tests/corpus/information-register-slices](../tests/corpus/information-register-slices).
Доказательства, планы, аудиты, публичные пакеты и отчёт —
[result/storage-backed-information-register-slices](../result/storage-backed-information-register-slices).
