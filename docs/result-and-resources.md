# Query API, результат и ресурсы — №44

Реализован общий ограниченный адаптер XBQL → типизированный AST → Script →
storage → независимая SBSL-оценка. Выполнение не зависит от названий проектов,
Python не вычисляет бизнес-строки, expected отсутствуют в плане и renderer.

## Исполняемый контракт

- Литералы запросов сохраняют captured параметры; типизированный
  `ПроизвольныйЗапрос` принимает постоянный текст и именованные `&Name`.
  `УстановитьПараметр` допускает неизвестные имена и повторную установку.
  Отсутствующее значение и неверный тип проверяются при `Выполнить` в Script.
  Параметры IN могут быть скалярными массивами с доказанным исходным типом.
  Повторное выполнение читает текущее staging-хранилище и создаёт новые строки.
- Receiver разрешается по локальному исходному объявлению запроса/результата
  до адаптации. Проектные модули, структуры, callback и одноимённые методы
  сохраняют свой контракт. Переприсваивание и неподтверждённые alias-потоки
  остаются недоступны. Исходный текст и диапазоны сохраняются; внутреннее
  преобразование `&` в `%` не меняет длину текста и защищает строки/комментарии.
- `РезультатЗапроса<T>` получает конкретный номинальный тип строк. Поддержаны
  один обход, `ВМассив`, `Пусто`, `Первый`, `ПервыйИлиНеопределено`,
  `Единственный`, `ЕдинственныйИлиНеопределено`, идемпотентный `Закрыть`.
  Последняя полученная строка и пустой результат освобождают ресурс автоматически.
  Второй обход и обход после явного закрытия отклоняются. Пустой автоматически
  закрытый результат допускает свой первый пустой обход.
- AST-преобразование `для` сохраняет порядок, continue, break, return и throw;
  доступны переменная результата и непосредственный `Q.Выполнить()` в цикле.
  `исп` доказанного результата закрывается в finally на границе своей области,
  включая вложенные области и досрочный выход. В trace фиксируются open/close.
- `ПОРОДИТЬ Имя` создаёт readonly поля по проекциям, имя и номинальная
  идентичность принадлежат исходному модулю. Публичного конструктора нет.
  Аннотация видимости сохраняется в AST; межмодульная видимость пока недоступна.
- `ЗАПОЛНИТЬ` сначала сопоставляет имена, затем позиции. Позиционное заполнение
  использует порядок конструктора; дополнительные обязательные параметры
  отклоняются, умолчания и readonly сохраняются. Общий mapping применяется
  к простым запросам, joins, projections и composites. Поддержана исходная
  скалярная структура с `обз`, `знч`, literal-умолчаниями и конфигурацией
  `@ИменованныеПараметры конструктор`, подтверждённой native-пробой.

Режим результата включается через `queryResults: true`, доказанное использование
`Закрыть`, сигнатуру `РезультатЗапроса<T>` или динамический Query API. Прежние
критерии без этих признаков сохраняют режим materialized-array. Конкретный
режим и действительный rowType отражены в execution plan.

## Основание и ограничения

Справка Элемента **9.3** прочитана в авторизованном браузере, ссылки и контракт
сохранены в [reference-9.3.json](../tests/corpus/result-resources/reference-9.3.json).
Установленный Script **10.0.2-1** запускается в режиме `current`; отдельного
режима `-c 9.3` нет. Исходные версии архивов и переносимых проектов **9.0**
сохранены. Native-пробы подтверждают методы конкретной структуры и конфигурацию
конструктора, сохраняют отказы XBQL, пользовательского generic и наследования
пользовательского ресурса от `Закрываемое`.

В executor результат — материализованные строки с состоянием однократного
обхода; это не native курсор базы. Native XBQL/права, динамически вычисляемый
текст и изменение `Текст`, внешние `.xbql` с неподтверждённым вызывающим API,
дескрипторы колонок/доступ по индексу, пользовательские источники,
nullable narrowing при чтении, межмодульные порождённые типы и произвольные
платформенные конструкторы не подтверждены. Исторический шаблон
`ЗапросСВыборкой(Text)` сохранён как UNSUPPORTED; переносимый подтверждённый
`ПроизвольныйЗапрос` проверяется отдельными критериями. Неразрешённые сочетания
сохраняются в очереди №45.

## Приёмка и доказательства

**35 различных целевых тестов успешны:** 14 новых и 21 затронутый прежний
(16 plan и пять runtime). Два переносимых проекта используют справочник и
периодический регистр; авторские данные/ответы записаны до выполнения.
Проверены пустые результаты, явное и автоматическое закрытие, повторные
снимки, ранний return, break, continue, исключение, вложенные области,
передача типизированного результата и named/positional/local constructors.
Шесть исполнимых бизнес-мутаций получили **SBSL FAIL**, альтернативная корректная
реализация — PASS; инфраструктурный ERROR восстановился в PASS.

Два неизменённых прямых корня `ДанныеКонтрагентов` и `ДанныеНоменклатуры` из
Prakticheskie независимо оценены. Четыре точных старых review templates
исполняются в новом переносимом проекте. Memory и четыре PostgreSQL-сценария
проверяют свежие снимки, изменения/rollback, независимый SQL-аудит и cleanup;
`source:commit` отсутствует. Public test/run — **2/2**, контроль —
**FAIL → UNSUPPORTED → PASS**, unavailablePoints **1**. Два изолированных batch
— **3/0/3**, cacheHit false; **46 артефактов** соответствуют публичным схемам.
Валидация только новых YAML: 21 файл, ноль ошибок, три предупреждения
о контейнерах проектов вне области metadata-validator.

До реализации сохранены 260 выбранных записей каталога; явно добавлены 11
связанных внешних источников из неизменённого каталога. Обновлены только эти
**271** записи: **61 parsed**, **8 planned/executed/independentlyAssessed**
(два литерала, два API-вызова тех же прямых корней, четыре шаблона).
Каждое подтверждение связано с exact sourceHash/range, прямым критерием и
свежим runtime. Другие записи каталога сохранены; parsed не считается оценкой.
SHA-256 четырёх архивов совпадают с baseline. Прежние expected, лимиты и CI
не изменены.

Первичные сбои и отдельные повторы сохранены в `result/result-resources`.
Первый селектор прежнего FillPlanTest ошибочно включил полный read-only
discovery, упавший на отсутствующей идентичности владельца порождённого типа.
Проверка идентичности исправлена; полный discovery не повторялся по локальному
ограничению задания. Две ошибки путей записи доказательств в прежних runtime
тестах исправлены в обвязке повторного запуска. Полная регрессия, 303 формы,
44 прежних корня и четыре архивные validate оставлены nightly.

  test_query_results.ResultDockerTest test_query_results.ResultPublicTest

  test_query_results.ResultSqlTest

публичные пакеты; `run_native.py` сохраняет результаты пяти trusted native-проб.
