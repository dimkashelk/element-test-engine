## Текущие подтверждённые препятствия

Проба planner на текущей реализации, без запуска студенческого кода на host:

- Продажи::ЗаказФормаОбъекта.ПослеСоздания с context: `context допустим только как объект для модуля Объект`.
- Обработчик редактирования без context: `Перечисление ОбычнаяКоманда отсутствует, неоднозначно или не поддерживается`.
- Администрирование::ДанныеКомпании.ПолучитьДанные: `Неподдержанная аннотация достижимого метода: ДоступноСКлиента`.

Последняя причина возникает раньше доступа к НаборКонстант. Снятие первого
барьера не доказывает отсутствие следующих; их проверяет приёмочный корпус.
