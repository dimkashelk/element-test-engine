# Константы, обычная форма и часы — контракт этапа 35

Контракт фиксируется до реализации. Исполнение: Script 10.0.2-1, `-c 9.0`.
Python разрешает декларации и типизирует fixture; исходные методы строят
словари, приветствие и календарные результаты в Script. Оценка выполняется SBSL.

```yaml
constants:
  Администрирование::ДанныеКомпании:
    Телефон: '+7 123'
  Администрирование::РабочиеДни:
    Понедельник: true
clock:
  mode: fixed
  date: '2026-10-02'
  time: '06:00:00'
  timezone: UTC
executorLocale: ru-RU
snapshotConstants: true
snapshotArgs: true
```

`constants` — словарь owner → поля YAML `Константы`. Owner разрешается
в проекте, namespace/import целевого метода; разные spelling одного owner
отклоняются. Неизвестные поля, повторные декларации и неверные значения
отклоняются до записи Script. Поддержаны Строка, Булево, Число, Дата, Время
и nullable этих типов. Пропущенные поля используют YAML default, затем native
умолчание: "", false, 0, 0001-01-01, 00:00:00; nullable — null.
Системное Получить возвращает свежий типизированный снимок одной неизменяемой
подготовленной сессии. Локальные изменения снимка/словаря не меняют константы.
`snapshotConstants` оборачивает результат в `{result, constants}` и повторно
читает независимо подготовленные данные после исполнения. Нет записи/SQL.
Проектный Получить имеет приоритет; локальное имя не обозначает менеджер.

Обычная `Форма` не содержит Объект и не принимает lifecycle. Общий адаптер
№34 сохраняет свойства, вложенные компоненты, observe, contextPath и sequence.
Дополнение: ПолеВвода<Дата>.Значение: Дата (default 0001-01-01).
Кнопка и СобытиеПриНажатии принимают `{}`, API отсутствует. ПриНажатии
проверяется по YAML и собственной сигнатуре `(Кнопка, СобытиеПриНажатии)`;
настоящие UI-события и выражения не выполняются.

ДоступноСКлиента сохраняется с исходным диапазоном в IR. Standalone вызывает
тот же исходный метод локально; транспорт клиент/сервер не проверяется.
Неизвестные аннотации сохраняют отказ. Общие правила видимости действуют.

`clock.mode` — fixed или docker. Fixed требует date/time; docker запрещает
их. timezone — UTC или Europe/Moscow. Один DateTime снимок создаётся внутри
Docker до исходного метода, сохраняется в /tmp сессии и используется всеми
нулевыми native Дата.Сейчас()/Время.Сейчас(). Таким образом переход суток
не разделяет дату и время. Перехват привязан к AST и незатенённому native
owner; project Сейчас, параметры и локальные переменные не переписываются.
Сейчас с аргументами в clock-сценарии вне этого контракта.
В evidence сохраняются дата/время снимка, зона, mode и локаль. Host-время
и expected не задают часы. Без clock исходные native часы остаются native.

executorLocale явно принимает ru-RU или en-US. По умолчанию прежние формы
сохраняют en-US. Новые календарные задания задают ru-RU: ДеньНедели.
Представление() возвращает русские ключи, интерполяция Время — HH:MM:SS.
Native операции сравнения/ДобавитьДни/ДеньНедели не заменяются Python.
`snapshotArgs` оборачивает результат операции в `{result, args}` и наблюдает
реальные типизированные значения после вызова; значения sequence независимы.

## Документация и пробы

Сверены официальные [Дата](https://1cmycloud.com/console/help/lang/docs/stdlib/Std/Time/Date_ru/),
[Время](https://1cmycloud.com/console/help/lang/docs/stdlib/Std/Time/Time_ru/),
[ДеньНедели](https://1cmycloud.com/console/help/lang/docs/stdlib/Std/Time/DayOfWeek_ru/),
[словарь](https://1cmycloud.com/console/help/lang/10.0/docs/topics/map-type/).
Документация сейчас показывает Сейчас с обязательным ЧасовойПояс; проба
Script режима 9.0 подтверждает также нулевой вызов. Документация констант/UI
Элемента 9.1 перенаправляет на вход; её сигнатуры не считаются подтверждёнными.
Адаптер чтения констант/UI ограничен явным контрактом YAML исходного дампа.

Calendar.sbsl проверяет переход месяца/года/29 февраля, defaults, отсутствующий
ключ и две локали. Получить и индекс отсутствующего ключа выбрасывают
Std::IllegalArgumentException; ПолучитьИлиНеопределено возвращает null.
ru-RU даёт Пятница и 01:02:03; en-US даёт Friday и 1:02:03 AM.
ДатаВремя.Дата()/Время() отсутствуют; снимок разделяется native-конструкторами
по компонентам. Инициализатор mutable module state не поддерживается; часы
сохраняются в приватном /tmp отдельного контейнера. Первичные отказы сохранены.


## Оболочки наблюдения и Docker oracle

snapshotArgs возвращает `{result: прежнийActual, args: реальныеАргументы}`;
snapshotConstants оборачивает это в `{result, constants}`. В sequence каждый
шаг сохраняется через JSON до следующего вызова. Ошибка отсутствующего ключа
может наблюдаться только при явных `captureException: true` и
`captureExceptionTypes: [ИсключениеНедопустимыйАргумент]`; другие прежние
инфраструктурные ошибки не перехватываются этим расширением.

При `clockOracle: {greetings: [ночь, утро, день, вечер], workWeek: {...},
timePrefix: Сейчас}` независимый SBSL заменяет маркеры `__clock.date__`,
`__clock.timeText__`, `__clock.dayText__`, `__clock.greeting__` в expected
по снимку до вызова. Он использует явные семь русских имён дней и авторскую
неделю, собственные часовые границы 6/12/18; ни actual, ни исходный helper
не участвуют в oracle. Этот контракт предназначен для приветственного
календаря, а renderer остаётся общим. Oracle не включается в IR/driver.
JSON времени имеет native ISO-формат: нулевые секунды могут отсутствовать,
например `00:00`; формат надписи независимо подтверждён как `00:00:00`.
