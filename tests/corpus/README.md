# Корпус регрессии алгоритма

`names` проверяет границы методов, строку с текстом `метод`, интерполяцию,
вложенный блок, одинаковые краткие имена модулей и типов в разных подсистемах,
локальный выбор и импорт с алиасом. `broken` содержит незакрытый метод:
его индекс должен быть неполным, а runtime не должен извлекать усечённое тело.

В `assignment.yaml` структурные ожидания и сравнение `expected` выполняет SBSL.
Статусы строк по порядку: `PASS`, `PASS`, `FAIL`, `PASS`, `PASS`, `FAIL`,
`ERROR`, `UNSUPPORTED`. Для двух последних строк тест подставляет
контрактные результаты окружения. Это **мок**; он не утверждает, что Script
executor сам выдаёт `ERROR` или `UNSUPPORTED` в этих условиях. `runtime_pass`
и `runtime_negative` используют фактическое значение 5, отдельно подтверждённое
локальным Script executor на доверенной фикстуре. Студенческий код в обычном
`run`/`batch` по-прежнему исполняется только в Docker. Исходные фикстуры
проверяются на неизменность в тесте.
