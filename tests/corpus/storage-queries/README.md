# Корпус задания №31

`catalog` и `document` — переносимые проекты с разными namespace, именами,
полями, aliases и видом хранения. Код сценариев выполняется в Docker;
Python только создаёт план/инфраструктуру. Неизменённый реальный поиск находится
в исходном `Prakticheskie-primery-2026-09-30-15-20.xdump`.

Сценарии: строковые/числовые/ссылочные параметры, nullable-проекции,
конъюнкция, сортировка в обоих направлениях/по двум полям, лимит, обход,
пустота/единственность, исходные A → B → C, побочные записи в параметрах,
повтор Выполнить, detached-строки, captured reference identity, nested
параметр, ресурсный снимок, handler после записи, commit/rollback и недоступный JOIN.
`BatchIsolated` требует пустое состояние до записи, поэтому две работы с
одинаковым UUID обнаружат утечку состояния, если сессии начнут его разделять.

Преподавательские ожидания хранятся отдельно в `assignments/storage-queries-*`.
Контрольный assignment даёт FAIL/UNSUPPORTED/PASS. Тесты делают независимые
мутации проекции, источника, предиката/параметра, зависимости, сортировки,
лимита и момента чтения, оцениваемые через настоящий SBSL.

`native-probes` содержит только доверенный код для Script `-c 9.0`:
Query — ожидаемый отказ неизвестного литерала; Values — native значения,
Parameters — порядок/фиксация, Readonly — ожидаемый compile refusal.
Это не студенческие проекты. Документация контракта —
[storage-backed-queries.md](../../../docs/storage-backed-queries.md).
