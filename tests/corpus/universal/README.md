# Переносимый корпус №29

`chain` — оригинальный Main → B → Math.C, callback и константы, невыбранная
ветвь Crash и достижимый неизвестный вызов. `crud` и `crud-renamed` — разные
namespace, методы, поля, ТЧ и тип ID; алгоритм движка общий. Ожидания находятся
в отдельных заданиях преподавателя `assignments/universal-*` и не читаются
planner/renderer/backend. SQL-варианты используют те же исходники.

`tests/test_universal_runtime.py` дополнительно проверяет структуры/типы по
владельцам, каталог, регистр, старый снимок для обработчика, свежие копии,
rollback, реальные трассы, ошибку зависимости, инфраструктурный сбой SQL и
цепочку из 1200 методов. Во всех source fixtures бизнес-логика остаётся XBSL.
