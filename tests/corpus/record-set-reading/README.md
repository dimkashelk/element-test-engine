# Корпус чтения наборов №32

- `information`: namespace Data/Entry/Service, периодический Prices, два
  измерения, два ресурса и nullable-ссылка; импортированные алиасы,
  зависимость возвращает набор, параметр принимает набор.
- `accumulation`: namespace Учет/Вход, другой язык имён, типизированный
  документ-регистратор, период/вид движения/активность и два ресурса.
- `native-probes`: доверенные standalone Script-пробы режима 9.0; не исходники
  проверяемых работ.

Реальный третий источник — неизменённый Prakticheskie-primery xdump,
метод ПараметрыЗаписи::КурсыВалют.Пересчитать.

Teacher-данные и независимые ожидания — `tests/record_set_fixtures.py`.
Генерация публичных YAML-заданий: `python3 tests/record_set_fixtures.py`.
