# Переносимые fixtures задания 54

`ordinary`: Data/Other, Card, Item, Choice, Rows.
`renamed`: Учет/Архив, Запись, Узел, Связь, Детали.
Оба владельца ссылки получают один ID; строки ТЧ включают A/B/NULL и повторы.
Hooks записывают движение, наблюдают `До`, изменяют его копию и могут отказать
после записи. Main проверяет тип/равенство, сохранение/загрузку, запрос и свежее
чтение ссылки. Отчёт читает ссылку и представление через формулу.

Независимые входы/ожидания: `tests/tagged_reference_fixtures.py` и
`assignments/tagged-reference-unions/assignment.yaml`. Мутации metadata для
обязательности/nonnullable, формы справочника и union-ресурса выполняются в
временных копиях fixtures. UUID-профиль также использует временную копию исходника.

```bash
ELEMENT_TEST_DOCKER_TESTS=1 PYTHONPATH=.:tests \
  python3 -m unittest test_tagged_reference_unions -v
```

PostgreSQL создаётся и удаляется изолированно; пароль генерируется в окружении
теста. SQL-аудит сверяется с состоянием преподавателя. Публичное задание содержит
PASS/намеренный FAIL/UNSUPPORTED; batch проверяет также мутацию исходника.

Финальный дамп используется отдельным preflight-тестом только для плана и
генерации. Эти fixtures не являются бизнес-приёмкой денежных операций Dvizhok.
