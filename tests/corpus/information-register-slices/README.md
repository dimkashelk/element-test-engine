# Независимый корпус задания 33

`prices` и `renamed` — самостоятельные проекты с разными namespace, owner и
ресурсами. У каждого три измерения (два nullable ссылочных типа), два ресурса
и два реквизита. Одинаковые UUID товаров/поставщиков намеренны. Импортированные
методы вычисляют исходные параметры и фиксируют порядок эффектов.

Истории и ожидаемые результаты задаёт `tests/slice_fixtures.py`, независимо
от исходных запросов. Будущая строка 9999-12-31 проверяет объявленную UTC-границу.
Точные сценарии равных дат используют дополнительные поля сортировки.

`native-probes` — отдельный доверенный код Script 9.0. Он подтверждает
Дата/nullable-ссылки и отсутствие native Запрос. Студенческий код исполняется
только в изолированных Docker-контейнерах. Реальный архив остаётся неизменённым.
