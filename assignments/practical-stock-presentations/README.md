# Представления товаров в наличии

Проверяется оригинальный метод
`МетодыРаботыСКоллекциями::РаботаСКоллекциями.ПолучитьПредставленияТоваровВНаличии`
из `Prakticheskie-primery-2026-09-30-15-20.xdump` в режиме совместимости 9.0.

Независимая постановка находится в
`МетодыРаботыСКоллекциями/Служебное/ОписаниеПримера_ПоследовательнаяОбработкаКоллекции.xbsl`,
метод `ПостановкаЗадачи`: преобразовать данные товаров в массив представлений,
отобрав товары в наличии и упорядочив их по убыванию цены. Сравнивается поле
`Стоимость`; количество определяет наличие, а не множитель стоимости.

Авторский контракт оценочного задания уточняет:

- В наличии означает `Количество > 0`, включая положительные дробные значения.
- Нулевое и отрицательное количество исключается; пустой вход даёт `[]`.
- Стоимость может быть нулевой или отрицательной: ограничений знака в постановке нет.
- Каждая входная строка даёт одно представление; одинаковые строки сохраняются.
- Строка имеет вид `В наличии: <Наименование> Стоимость: <представление числа>`.
  Пробелы, наименование и стоимость сравниваются точно. Этот формат является
  уточнением задания, поскольку сама постановка не определяет пунктуацию.
  Он согласован с шаблоном оригинального метода. В оформленном фрагменте
  примера есть дополнительная запятая после имени, которая в это задание не входит.
- Числа форматируются стандартной интерполяцией `${...}` в настроенном Docker
  executor: 1000 → `1,000`, 2000 → `2,000`. Это проверено отдельным доверенным
  скриптом, без вызова целевого метода. Ожидания относятся к этому окружению;
  при смене локали нужно отдельно проверить форматирование.
- Порядок разных товаров с одинаковой стоимостью не оценивается: постановка
  не задаёт разрешение равенства. Проверка повторов использует одинаковые строки.

Ожидаемые фильтрация и порядок заданы вручную по этим правилам; они не вычисляются
из результата проверяемого метода. Исходная бизнес-логика исполняется в Docker;
оценку и сравнение массивов выполняет SBSL.

| Критерий | Вес |
|---|---:|
| Сигнатура `Обходимое<ДанныеТовара>` → `ЧитаемыйМассив<Строка>` | 1 |
| Исходный пример: Покрывало, затем Одеяло; Подушка исключена | 2 |
| Пустой вход | 1 |
| Только нулевое и отрицательное количество | 1 |
| Единственный товар в наличии | 1 |
| Три разных стоимости, вход не упорядочен | 2 |
| Положительное дробное количество | 1 |
| Положительная, нулевая и отрицательная стоимость | 1 |
| Два одинаковых товара сохраняются | 1 |
| Кавычка, `${probe()}` и перевод строки остаются данными | 1 |
| **Всего** | **12** |
